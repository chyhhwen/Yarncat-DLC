# 毛球貓 DLC

[毛球貓 YarnCat](https://github.com/chyhhwen/Yarncat) 的 DLC。一個 `.yarncat` 檔就是一個 DLC，挑喜歡的裝，也可以全部一起裝。

| DLC | 檔案 | 內容 | 需要版本 |
| --- | --- | --- | --- |
| [萬聖節](#萬聖節) | `festival/halloween.yarncat` | 黑貓毛色、萬聖節帽子、南瓜燈 | 1.6.0 |
| [老大貓](#老大貓) | `boss.yarncat` | 老大毛色、小魚乾玩具 | 1.6.0 |
| [健身貓](#健身貓) | `gym.yarncat` | 健身毛色、三件健身器材 | 1.5.0 |
| [掃地機器人](#掃地機器人) | `vacuum.yarncat` | 會自己打掃的掃地機器人 | 1.5.0 |

## 安裝

1. 點系統匣的貓咪圖示，到「系統」分頁按「打開 DLC 資料夾」（`圖片\YarnCat\dlc`），把 `.yarncat` 檔放進去。
2. 在同一個分頁按「結束毛球貓」，再重新打開。
3. 毛色到「毛色」分頁選、配件到「配件」分頁選、玩具到「狀態」分頁選；家具會直接擺出來，不要的到「家具」分頁收起來。

載入了哪些、有沒有出錯，寫在「打開 DLC 資料夾」底下。不要了就刪掉檔案再重開。

以前的 `boss-gym.yarncat` 已經拆成 `boss.yarncat` 和 `gym.yarncat`，舊檔請刪掉。

DLC 是程式碼，只裝信任的人給的檔案。

## 萬聖節

- **黑貓**（毛色）：一身黑、琥珀色眼睛。
- **萬聖節帽子**（配件）：每一隻貓都戴，毛色不同戴的也不同：黑貓巫婆帽、藍灰南瓜帽、橘貓蝙蝠髮夾、黑白賓士惡魔角。隔壁的客人也戴（對方也要裝）。
- **南瓜燈**（家具，只在 10/1～11/1）：貓會躲進去從眼睛的洞偷看。點一下：裡面有貓就蹦出來嚇你，沒貓就掉一顆糖果給貓撥著玩。

黑貓和帽子一年到頭都在。

## 老大貓

- **老大**（毛色）：缺耳、額頭有疤的橘紅大公貓，會巡視地盤。
- **小魚乾**（玩具）：每一隻貓都會叼著走、趴著啃。從牠嘴上抽走，牠會跟著討；拿太高太久就瞪你。

## 健身貓

- **健身**（毛色）：綁紅頭帶的白貓，比別的貓更常去練。
- **健身器材**（家具）：臥推椅、跑步機、高拉背機，每一隻貓都會去練，點一下叫貓過去。跑步機點一下加速，高拉背機點一下加重量，太快太重會被甩出去。

## 掃地機器人

- **打掃**：隔一陣子自己出來掃，吸掉便便和灑出來的貓砂，偶爾輾過便便拖一路。點一下出發或停下。
- **貓**：第一次會嚇到炸毛，習慣後會偷偷靠近、跳上去搭便車，累了趴在上面睡。

![貓被掃地機器人嚇到炸毛、搭便車、趴在上面睡覺，機器人輾過便便](/img/vacuum.png)
